# Quote It

Quote It creates quotations with links to their sources for reuse in Joplin and elsewhere.

## Language

**Internal source link**:
A link to the Joplin note from which a quotation or link was copied.

**External source link**:
A link to the original web page associated with the source note. A usable external source is an absolute HTTP or HTTPS URL.

**Source heading**:
The heading associated with the beginning of the selected quotation, used to provide more specific attribution.

**Attribution**:
The source information attached to a quotation, including a link and its display label.
