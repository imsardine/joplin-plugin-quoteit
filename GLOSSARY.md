# Quote It

Quote It creates quotations with links to their sources for reuse in Joplin and elsewhere.

## Language

**Source note**:
The Joplin note from which a passage or source link is copied. It may contain the user's own writing or material clipped from the web.

**Quotation**:
A selected passage copied with attribution to its source.

**Internal source link**:
A link back to the source note in Joplin.

**External source link**:
A link to the original web page associated with the source note. A usable external source is an absolute HTTP or HTTPS URL.

**Source heading**:
The heading associated with the beginning of the selected quotation, used to provide more specific attribution.

**Attribution**:
The source information attached to a quotation, including a link and its display label.

**Explicit external anchor**:
A fragment supplied with or associated with a source heading that identifies a location on the original web page.

**Inferred external anchor**:
A best-effort fragment derived from a source heading when no explicit external anchor is available. Its destination on the original web page is not verified.
